# Novel Tracking Website

A modern reading tracker built with a React frontend structured like a standard Create React App project and a Python Flask backend that uses models, app, and seed files.

## Overview

This app helps readers track current reads, goals, reading sessions, notes, and statistics in one dashboard.

## Project structure

- frontend/: CRA-style React app using `src/App.js` and `src/index.js`
- frontend/public/: static assets and HTML shell generated by Create React App
- backend/: Flask API built from `models.py`, `app.py`, and `seed.py`
- backend/requirements.txt: Python dependencies

## Tech stack

- Frontend: React, CRA, Tailwind CSS, React Router, Recharts, Lucide React
- Backend: Python, Flask, Flask-SQLAlchemy, SQLite

## Quick start

### 1. Install frontend dependencies

```bash
cd frontend
npm install
npm start
```

The frontend runs at http://localhost:3000.

### 2. Set up the backend

```bash
cd backend
python -m venv .venv
. .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python seed.py
python app.py
```

The backend runs at http://localhost:5000.
